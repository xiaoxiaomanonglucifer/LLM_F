# v1 数据集质量分析报告

> 范围：R2（工程与数据）。数据快照为 2026-11-05 建成的 v1，整理日期 2026-11-12。
> 本文只分析语料、索引与图谱的数据质量，不包含 R3 的题库、LLM 评审和正式评测指标。

## 0. 结论摘要

v1 数据集为 **178 部法规 / 10,069 条法条 / 1,273,548 字**，通过采集完整性、解析结构、分布统计和可检索性检查，可以作为当前 RAG 主线的数据底座。

主要结论：

- 采集完整：目录 178 部，成功采集 178 部，缺失 0、错误 0，全部为现行有效版本。
- 结构干净：10,069 条法条无空正文、无重复 ID、无空辖区；结构告警 0。
- 范围相关：覆盖土地、矿产、水、森林、草原、湿地、海洋、能源、生态环境、国土空间规划和资源行政执法。
- 可检索：BGE-M3 1024 维索引 10,069 条；BM25 关键词索引参数固定；G0/G1/G2 链路已跑通。
- 图谱可用：8,943 条三元组，覆盖 88.82%；19,680 个节点、59,760 条关系；11 项结构校验 0 失败。
- 主要缺口：规模低于开题预估的 2 万~5 万条；处罚召回约 87.2%，仍有约 164 条含明确处罚词的法条未入图谱；正式题库尚未交付。

采集链路为：标题检索 → 详情接口 → docx 下载地址 → 下载 docx → 校验 ZIP 魔数 → 记录 sha256。除国家法律法规数据库外，未使用其他法规网站。

## 2. 分析流程

数据分析按以下六步进行，所有统计均由 `articles.jsonl`、`documents.jsonl`、`manifest.json` 等原始文件计算，未手工修改数值。

1. **采集完整性**：目录条目与实际采集结果、缺失、错误、版本状态逐项核对。
2. **解析与切分质量**：docx 转文本后按“第X条”切分，检查条号、重复、空正文和文档条数一致性。
3. **描述统计**：统计法规数、法条数、字数、条长分布、每部条数，以及层级、领域、辖区分布。
4. **范围与相关性**：核对收录领域、国家和地方比例、行政程序类法规的用途，以及未纳入范围。
5. **可检索性**：构建 BGE-M3 向量索引和 BM25 索引，用真实问题检查 top-k 命中，并运行 dev 冒烟。
6. **图谱质量**：统计三元组覆盖率、实体和关系规模，回验原文，执行 Cypher 结构校验和处罚召回抽查。

## 4. 结构质量与切分

### 4.1 切分方法

- 读取 docx 正文，跳过目录、重复标题和页眉页脚干扰。
- 以“第X条”为边界切分法条，条内款、项、但书原样并入本条。
- 保留 `chapter`、`section`、`article_no`、`article_num`、`citation` 等元数据。
- `article_id` 由 `doc_id + 条号` 生成，重复条号追加后缀。

## 6. 范围与相关性分析

### 6.1 相关性口径

目录以土地、矿产、水、森林、草原、湿地、海洋、能源、生态环境、国土空间规划及资源行政执法相关文本为准。行政程序类法规（行政处罚、行政许可、行政复议、行政诉讼等）作为处罚和许可依据纳入，不是领域实体法。

### 6.2 需要说明的边界

- 行政程序类共 18 部、1,116 条，占全部法条的 11.1%。汇报时建议分“核心实体法”和“行政程序法”两类列示。
- 未纳入全国其他省市的地方性法规，避免与云南/昆明应用场景不相关。
- 开题报告提到的自然资源部政策文本未纳入；本次范围是法律、行政法规和地方性法规。
- 旧目录中 12 部无现行有效精确匹配的法规未纳入；已被新法替代的旧文本以现行法为准。
- 规模为 10,069 条，低于开题预估的 2 万~5 万条。这是真实测量结果，没有通过拆条、复制文本或纳入无关法规虚增。

### 6.3 分布对评测的影响

- 全国法条占 81.8%，如果按语料随机抽题，全国法题目会占绝对多数，地方检索能力测试不足。
- 建议 R3 按辖区或层级分层出题，例如 60 题中全国 30、云南 15、昆明 15；并按层报告指标。
- 单部《生态环境法典》占 12.3%，抽样时应对超长法规设上限或分层，避免题目集中。

### 7.2 检索链路

- 融合：RRF，`rrf_k=60`，取 `top_k=5`。

### 8.3 处罚召回抽查

处罚节点 133 个是去重后的处罚名称，不是 133 条处罚规定。处罚关系共 2,076 条，其中 17 个规范类型覆盖 1,714 条（82.6%），其余 362 条为原文短语变体。

按明确处罚词统计：

| 指标 | 数值 |
|---|---:|
| 含明确处罚表述的法条 | 1,278 |
| 图谱中有处罚边 | 1,114 |
| 召回率 | 87.2% |
| 漏抽合计 | 164 条（154 条有三元组但处罚为空 + 10 条无三元组） |

漏抽的典型原因是模型把“责令改正”归入 `actions`，或对部分罚款条款只抽了主体、未抽处罚。示例包括《昆明市燃气管理条例》第三十九、四十、四十二、四十三、四十六条和《昆明市城市地下管线管理条例》第三十六条。

处理建议：在 R3 正式实验前，对 `penalties` 为空但原文含明确处罚词的记录做规则回填，补入标准处罚类型；不重跑全量 LLM。回填后需重新导出 Cypher 并重跑 11 项结构校验。

## 9. 风险与局限

| 风险 | 影响 | 处理 |
|---|---|---|
| 规模低于开题预估 | 评审可能追问数据量 | 如实说明范围为全国+云南/昆明相关现行法规；后续可扩充目录，切分与索引代码不变 |
| 全国法条占 81.8% | 地方场景测试不足 | 答辩中说明法律层级；R3 按辖区/层级分层出题 |
| 单部法典占 12.3% | 随机抽样可能偏斜 | 出题时对超长法规设上限或分层 |
| 处罚召回 87.2%（漏 164 条） | G2 处罚类问题上下文不完整 | 正式实验前规则回填并重新校验 |
| G0 参数知识泄漏 | G0 组可能引用条文 | 正式评测按 R3 口径处理并披露 |
| 正式题库未交付 | 无法形成正式结论 | 等 R3 交付 `data/eval/v1/questions.jsonl`（≥60 题） |
| Neo4j 未实际导入 | DB 层计数未验证 | 部署机导入后核对 19,680 节点 / 59,760 关系 |
| BGE-M3 最大 512 token | 超长法条尾部语义可能被截断 | 原文完整保存在 `document` 字段，生成时仍使用全文；BM25 兜底关键词 |

## 10. 总结

v1 数据集在完整性、结构质量、领域相关性和可检索性上达到了当前阶段的要求：

- 178 部法规全部采集成功，10,069 条法条结构告警 0。
- 语料规模 127.4 万字，覆盖 7 个领域，国家和地方辖区比例可解释。
- BGE-M3 向量索引和 BM25 索引均已建成，G0/G1/G2 链路已跑通。
- 图谱覆盖 88.82%，结构校验通过；处罚召回仍有约 164 条缺口，需在正式实验前补全。

当前不应把 dev 冒烟当作正式结果；正式结论依赖 R3 的题库、评审和统计检验。
