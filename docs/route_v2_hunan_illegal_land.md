# 开题答辩后的 v2 技术路线：聚焦湖南非法占地行政处罚

> 依据 2026-10-27 开题答辩录音整理。录音为课堂环境，个别词句可能有转写误差；
> 下文按语境校正，关键结论建议再向苗老师确认一次。
> 本文件只调整**研究边界与技术路线**，不改项目题目，也不推翻已完成的法规 RAG 工程。

## 一、老师反馈的三个核心问题

1. **范围太泛，缺少真实业务价值**
   - 原方案覆盖国土资源全领域、数十部法规；老师明确说“所有法律都做，外边专家一看就知道太泛，基本没什么价值”。
   - 建议聚焦到一个具体业务、一个具体地区，先把“案件事实 → 适用法条 → 处罚结果”这条链跑通。

2. **缺少真实办案数据，尤其是行政处罚决定书**
   - 老师反复强调：处罚决定书里会写“违反了《X法》第 Y 条”“依据《Z法》第 W 条”“罚款多少、怎么裁量”。
   - 这类文本才能提供“行为—法条—处罚”的真实监督信号；只拿法条做语义检索，系统仍然不懂办案。
   - 老师提到湖南等省公开过一批自然资源处罚决定，并愿意分享部分数据。

3. **技术路线停留在表面**
   - 不能只做“问一个问题、检索几条法条、让大模型回答”。
   - 要像法官/法律专家一样：先识别违法行为和法律关系，再关联多部法律的具体条款，最后按裁量基准给出处罚建议。
   - 题目可以不改，但技术思路要落到真实数据与真实判断流程上。

## 二、修订原则

- **题目不变**：仍为“基于检索增强生成与知识图谱的国土资源法律法规智能问答系统”。
- **范围收窄**：从“国土资源全领域”收窄为“湖南省·未经批准非法占用土地（含超过批准数量占用）的行政处罚”。
- **案例驱动**：以公开行政处罚决定书为核心数据，法条库作为依据层，不再把“法条问答”当作唯一任务。
- **保留已有工程**：`data/v1/` 的 75 部法规、4,104 条按条切分、BM25/Chroma 索引、G0/G1/G2 流水线继续使用，新增案例层与案件图谱。
- **可复现**：案例同样版本化，记录来源 URL、采集时间、sha256；实验输入去除处罚结果，避免标签泄漏。

## 三、选题边界

| 维度 | 纳入 | 不纳入（本期） |
|---|---|---|
| 地区 | 湖南省（省厅及市州/县市区公开决定书） | 其他省份（只作对比/泛化讨论） |
| 违法行为 | 未经批准占用土地；超过批准数量占用土地 | 非法采矿、非法转让土地、规划违法、权属争议 |
| 法律层级 | 国家法律、行政法规、部门规章、湖南省地方性法规、省厅裁量基准 | 村规民约、内部文件、非公开案卷 |
| 处罚类型 | 责令退还、限期拆除、没收建筑物、罚款、处分/移送 | 刑事判决、民事赔偿 |
| 任务 | 违法定性、违法条款检索、处罚依据检索、裁量建议、带引用问答 | 全领域法律咨询、合同审查 |

**为什么选湖南**

- 老师明确提到湖南公开处罚决定书较多，且 `湘自资规〔2022〕1号` 裁量基准把罚款按“公益/非公益 × 永久基本农田/其他耕地/其他土地”分档，金额可计算、可核验。
- 已核实多个公开入口有持续更新：永州市局处罚台账、江永县决定书、祁阳市决定书、湘乡市决定书、邵阳市决定书等（见附录）。
- 湖南省级法规在 FLK 可检索到现行有效版本，可与国家法条组成完整依据链。

## 四、数据方案

### 4.1 法规层（依据库）

在现有 `data/v1/` 基础上补充湖南地方立法与裁量文件：

| 类别 | 文件 | 用途 | 来源 |
|---|---|---|---|
| 国家法律 | 土地管理法（第 2、44、77 条） | 违法定性、处罚依据 | FLK，已在库 |
| 行政法规 | 土地管理法实施条例（第 57 条） | 罚款幅度 100–1000 元/㎡ | FLK，已在库 |
| 国家法律 | 行政处罚法（第 32、33 条） | 从轻/减轻/不予处罚 | FLK，已在库 |
| 部门规章 | 自然资源行政处罚办法 | 立案、管辖、程序、处罚种类 | 司法部/自然资源部公开文本 |
| 湖南地方法规 | 湖南省实施《土地管理法》办法（2022） | 地方适用细则 | FLK，sxx=3 |
| 湖南地方法规 | 湖南省基本农田保护条例 | 永久基本农田特别保护 | FLK，sxx=3 |
| 湖南地方法规 | 湖南省土地监察条例 | 执法权限与程序 | FLK，sxx=3 |
| 湖南裁量基准 | 湘自资规〔2022〕1号 | 罚款分档与从轻从重 | 湖南省自然资源厅/市州政府公开页 |
| 湖南免罚清单 | 自然资源领域不予处罚清单（2025） | 不予处罚情形 | 湖南省自然资源厅公开页 |

裁量基准（以 `湘自资规〔2022〕1号` 原文为准，以下为公开解读中的数字）：

| 地类 | 公益项目 | 非公益项目 |
|---|---|---|
| 永久基本农田 | 500–600 元/㎡ | 600–1000 元/㎡ |
| 其他耕地 | 300–400 元/㎡ | 400–500 元/㎡ |
| 其他土地 | 100–200 元/㎡ | 200–300 元/㎡ |

这组数字是 v2 的关键：系统不能只引用“第 77 条”，还要能根据**地类、面积、项目性质、从轻从重情节**算出罚款区间，并解释取上/下限的理由。

### 4.2 案例层（核心新增）

目标：收集 **80–100 份**湖南非法占地行政处罚决定书/台账记录，其中 **60 份作为 gold 评测集**，20 份作为开发集；其余可作为检索示例库。
当前已完成 **11 份试点**（`data/cases/v1/cases.jsonl`），用于冻结 schema 与跑通五步问答；
扩大采集按同一字段契约追加。实际字段以 `docs/data_contract.md` 第 5.2 节为准，
下列 JSON 为早期字段示意。

已核实的来源类型：

- 市州自然资源和规划局“行政处罚台账”（如永州 2025 年台账，含 12 条记录，字段有文书号、违法类型、依据、事实、罚款、没收金额、处罚内容、日期、机关、相对人）。
- 县市区自然资源局单份决定书（如江永县 2025 年多份、祁阳市、湘乡市、邵阳市、洞口县）。
- 省厅“以案释法/典型案例/复议诉讼案例”，作为补充与解释材料，不替代原始决定书。

采集字段（`data/cases/v1/cases.jsonl`，每行一案）：

```json
{
  "case_id": "hn-sy-2023-013",
  "source": {
    "url": "https://zrzy.shaoyang.gov.cn/...",
    "portal": "邵阳市自然资源和规划局",
    "collected_at": "2026-10-28"
  },
  "decision_no": "邵自资罚字(2023)13号",
  "decision_date": "2023-10-16",
  "agency": "邵阳市自然资源和规划局",
  "party": {"type": "单位", "name_masked": "某公司"},
  "facts": "未经批准擅自占用土地硬化进场道路……",
  "behavior": ["未经批准占用土地"],
  "land_use": [
    {"type": "耕地", "area_m2": 722},
    {"type": "园地", "area_m2": 315},
    {"type": "林地", "area_m2": 163}
  ],
  "area_m2": 1282,
  "project_nature": "公益/非公益/未知",
  "violated_articles": ["law-land-admin#a0002", "law-land-admin#a0044"],
  "penalty_basis_articles": [
    "law-land-admin#a0077",
    "reg-land-admin#a0057",
    "hn-discretion-2022"
  ],
  "penalty_types": ["没收", "罚款"],
  "fine_amount": 336700,
  "fine_rate": [
    {"land": "耕地", "yuan_per_m2": 350},
    {"land": "其他", "yuan_per_m2": 150}
  ],
  "factors": ["……"],
  "text_path": "data/cases/v1/raw/hn-sy-2023-013.html",
  "text_sha256": "……"

```

字段说明：

- `violated_articles` 是“违反条款”，`penalty_basis_articles` 是“处罚依据条款”，必须分开标注——这是老师说的“法律关联”的核心。
- `fine_rate` 保留每平方米标准，便于核对“面积 × 单价 = 罚款”的计算链。
- `project_nature`、`factors` 用于解释裁量；缺失时标“未知”，不臆造。
- `party.name_masked` 对个人姓名、身份证号、电话做脱敏；单位名称可保留或统一编号，按组内合规约定执行。
- 原文另存 `raw/`，记录 sha256；分析与入库文本均对个人姓名/证件号/电话脱敏，
  `raw/` 与 `cases.jsonl` 保持一致；来源 URL 与原始页面哈希见 `manifest.json`。

### 4.3 采集与质检流程

1. **建目录**：`config/case_catalog.yaml` 登记来源站点、栏目、检索词、预计数量。
2. **抓取**：HTML 优先；PDF 用文本层提取；扫描件先做人工转录（先控制在 20 份以内，不引入 OCR 依赖）。
3. **解析**：正则 + 规则抽取文号、日期、面积、金额、条款号；人工复核关键字段。
4. **去重**：按 `decision_no` + 当事人 + 日期 + 面积去重；同一案件不同转载只保留原始来源。
5. **脱敏**：个人姓名/证件号/联系方式掩码；不采集非公开案卷。
6. **双人标注**：两人独立标注 `behavior / violated_articles / penalty_basis_articles / penalty_types / fine_amount`；不一致处由 R1 复核，报告 Cohen's Kappa（目标 ≥0.8）。
7. **版本化**：`data/cases/v1/` + `CHANGELOG.md` 记录新增/修订原因、时间、操作人。

### 4.4 数据切分与防泄漏

- **开发集 20 案**：用于提示词、检索参数、图谱 schema 调试。
- **评测集 60 案**：只用于最终实验；输入只给“违法事实”，去掉文号、机关、处罚结果、法条引用段落。
- **时间切分**：优先用 2023–2024 年案件做示例库，2025 年案件做测试；若数量不足，用案件级随机切分，但同一案件不得跨集合。
- **检索排除**：查询案件自身不得被相似案例检索召回；在检索器中按 `case_id` 过滤。
- 评测集构建由 R3 主导、R1 复核、R2 提供解析与数据契约。

## 五、知识图谱 v2：从“法条图谱”升级为“案件—法条—裁量图谱”

保留现有 Article—Subject/Action/Penalty 三元组，新增案件层：

```text
(:Case)-[:ALLEGED_BEHAVIOR]->(:Behavior)
(:Behavior)-[:VIOLATES]->(:Article)
(:Case)-[:CITES_BASIS]->(:Article)
(:Article)-[:PRESCRIBES]->(:PenaltyType)
(:Case)-[:SANCTIONED_WITH]->(:Penalty {type, amount})
(:Case)-[:HAS_LAND_TYPE]->(:LandType {name, area_m2})
(:Case)-[:HAS_FACTOR]->(:Factor)
(:Article)-[:PART_OF]->(:Law)
```

节点与边的最小集合：

- `Case`：案号、日期、地区、面积、罚款金额、项目性质。
- `Behavior`：先固定两类——`未经批准占用土地`、`超过批准数量占用土地`；后续再扩展。
- `Article`：直接复用 `data/v1/articles.jsonl` 的 `article_id`，保证与法条原文、引用格式一致。
- `PenaltyType`：责令退还、限期拆除、没收建筑物、罚款、处分、移送刑事。
- `LandType`：永久基本农田、耕地、园地、林地、草地、建设用地、未利用地、其他。
- `Factor`：公益项目、非公益项目、主动整改、配合调查、初次违法、面积较大、占用永久基本农田等。

构建方式：

- 案件字段用规则/正则抽取（面积、金额、条款号、日期），必要时用 7B 模型做候选抽取，再由人工复核；
- 法条节点来自现有语料，不重复造节点；
- 图谱质量由 R3 抽检 20%，报告边准确率与 Kappa；
- 导出 Neo4j Cypher，保留离线 `CaseGraphIndex` 作为实验默认路径，Neo4j 仅用于演示与查询。

## 六、检索-生成流水线 v2：模拟法律专家的判断链

### 6.1 输入

用户输入不再是泛泛的“法律问题”，而是**案件事实**，例如：

> 某公司未办理农用地转用审批，占用耕地 722 平方米、园地 315 平方米、林地 163 平方米硬化道路，属于公益项目，询问应如何处罚。

### 6.2 五步判断链

1. **事实抽取**：识别行为类型、地类与面积、审批状态、项目性质、是否占用永久基本农田、是否主动整改。
2. **违法定性**：映射到行为 taxonomy（未经批准占用/超批准占用），判断是否属于本次范围；事实不足时先追问或声明假设。
3. **法条适用**：检索“违反条款”（土地管理法第 2、44 条）与“处罚依据”（第 77 条、实施条例第 57 条、湖南裁量基准）；检查法律层级与特别规定。
4. **裁量计算**：按地类、项目性质、面积、从轻从重情节，给出罚款区间与计算式；引用相似案例作为参照。
5. **结论与依据**：输出结构化结论 + 原文引用 + 不确定性说明；超出范围或事实不足时拒答/澄清。

### 6.3 三组对照（保持归因控制）

| 组 | 检索上下文 | 目的 |
|---|---|---|
| G0 | 无检索，仅模型参数知识 | 基线 |
| G1 | 法条检索（稠密 + BM25，Top-K=5） | 法条 RAG 的增益 |
| G2 | 法条 + 相似案例 + 案件图谱（行为→条款→裁量） | 真实办案知识的增益 |

主实验仍为 G0/G1/G2；另做两项消融：

- **G2-case**：去掉相似案例与案件图谱，只保留法条检索（稠密 + BM25 + 法条图谱）+ 固定法条链，
  用于衡量“案例层”的净增益；
- **G2-graph**：去掉法条图谱，保留相似案例与案件图谱，
  用于衡量“法条图谱”的净增益。

这样可以把“案例”和“图谱”的贡献分开，回应老师对“技术路线要讲清楚”的要求。

### 6.4 生成格式（示例）

## 七、评测方案 v2

### 7.1 指标

| 任务 | 指标 | 说明 |
|---|---|---|
| 违法条款检索 | Recall@5、MRR | gold 为决定书中的“违反条款” |
| 处罚依据检索 | Recall@5、准确率 | gold 为“依据条款” |
| 处罚类型 | micro-F1 | 责令/拆除/没收/罚款等集合 |
| 罚款金额 | 区间命中率、MAPE、±20% 命中率 | 法律允许裁量，不要求逐元完全一致 |
| 引用准确率 | 生成引用与检索原文精确匹配 | 条文号必须真实存在 |
| 答案质量 | LLM-as-judge 0–3，≥2 正确 | 人工抽检 20% 校准 |
| 拒答/澄清 | 超范围与事实不足集的拒答率 | 对抗集单独统计 |

### 7.2 统计

- 60 案配对比较：McNemar（正确/错误）+ 配对 t 检验（评分），α=0.05；
- 检索指标报告 95% bootstrap 置信区间；
- 金额误差报告 MAE/MAPE，并按“公益/非公益、耕地/其他土地”分层；
- 三组两两比较用 Bonferroni 校正；
- 评测集与代码版本写入 `run_meta.json`。

### 7.3 基线之外的关键对照

- **仅法条 vs 法条+案例**：检验“真实办案知识”是否真的有用；
- **案例检索 vs 案件图谱**：检验结构化关联是否优于纯文本相似；
- **去掉裁量基准**：检验金额计算是否依赖裁量文件；
- **跨年份测试**：2025 案测试、2023–24 案做示例，观察时效泛化。

## 十、已确认的三项决策（2026-10-31）

1. **边界**：纳入“未经批准占用土地”与“超过批准数量占用土地”两类；临时用地、设施农用地
   只有在最终落入《土地管理法》第 77 条非法占地时纳入，并分别补充第 57 条、第 37 条作为
   特别审查依据。未按批准用途使用土地（第 81 条）、农村村民非法占地建住宅（第 78 条）、
   非法采矿、规划违法不纳入本期。
2. **数据**：老师暂不提供现成数据，由 R2 自行检索湖南公开行政处罚决定书/台账；
   当前已完成 11 份试点案例，目标仍是 80–100 份，按“开发集/评测集”切分，同一案件不跨集合。
3. **地区**：严格湖南。v1 的云南法规与 75 部全领域语料冻结保留，但**不进入 v2 检索**；
   v2 语料只含国家核心法 + 湖南地方立法 + 湖南裁量基准。
